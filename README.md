# E-Commerce Management System

## About the Project

This is a Java-based console application that simulates basic e-commerce operations. It allows administrators to manage products and customers to browse products, manage their carts, and place orders.

## Features

- Admin Registration and Login
- Customer Registration and Login
- Add, View, Search, Update, and Delete Products
- View Available Products
- Add and Remove Cart Items
- Place and View Orders
- Input Validation
- File Handling for Data Persistence

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Exception Handling
- File Handling
- Git and GitHub

## How to Run

1. Install the Java Development Kit (JDK).
2. Clone this repository.
3. Open the project folder in your terminal.
4. Compile the Java files according to the project structure.
5. Run the main class.
